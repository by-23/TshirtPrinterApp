# Отчёт: оптимизация киоска для Android по локальной сети

Дата: 2026-08-01  
Стенд: Playwright + Chrome DevTools (CPU ×4, медленный Wi‑Fi), экран 1080×1920.

## Как мерили

- Скрипт: `scripts/perf-kiosk.mjs`
- Отчёты: `docs/perf-reports/*.json` + скриншоты в `docs/perf-reports/screenshots/`
- **Эталон (baseline)** — Vite dev до правок (`http://127.0.0.1:5173/kiosk?native=1`)
- **Итог (final-after-all)** — production `vite preview` после всех правок (`http://127.0.0.1:4173/kiosk?native=1`)

Dev-эталон завышает JS (много мелких модулей). Для размера бандла важнее сравнение production: раньше один кусок ~1.3 MB, сейчас главный ~461 KB + ленивые куски.

## Цифры

| Метрика | Эталон (до) | Итог (после) | Изменение |
|--------|-------------|--------------|-----------|

| Первый осмысленный кадр (FCP) | 43 832 ms | 2 512 ms | ≈ **−94 %** |
| Число запросов | 304 | 86 | ≈ **−72 %** |

Production-сборка (vite build):

| Кусок | Размер |
|-------|--------|
| Главный `index-*.js` (киоск home) | ~461 KB (~141 KB gzip) |
| Редактор (по заходу) | ~68 KB + fabric ~282 KB |
| Оператор (по заходу) | ~107 KB |
| ИИ / оплата | ~21 / ~23 KB |
| Панели темы (только dev) | отдельный lazy-кусок, в release не качается |
| Мокапы «Популярные» | ~70–80 KB WebP вместо ~1 MB PNG каждый |

## Что сделано по этапам

1. **Стенд замеров** — `scripts/perf-kiosk.mjs`, каталог `docs/perf-reports/`.
2. **Разделение загрузки** — `React.lazy` для редактора, ИИ, оплаты, оператора; панели темы только в dev; Vite `manualChunks` (fabric, swiper, socket).
3. **Не держать старый экран** — после перехода предыдущий маршрут размонтируется; на слабых клиентах dissolve без blur; рамка «Популярные» без бесконечного spin.
4. **Локальные шрифты** — убраны Google Fonts из HTML и старта; UI на PT Sans Narrow / Barlow; шрифты принта — с точки `/files/fonts`.
5. **Превью каталога ×0.5** — sibling `*.thumb.webp` при scrape/ручной загрузке + backfill; галерея и баннер на превью, редактор — полный файл.
6. **Популярные** — 5 слайдов сохранены; мокапы в WebP; облегчены рамка/переходы на weak.
7. **Галерея** — `loading=lazy`, `decoding=async`, яркость в idle; Cache-Control на `/files` и UI dist.
8. **Сокет** — сразу HTTP статуса точки; Socket.IO после idle + опрос раз в 60 с.
9. **Скринсейвер** — `preload="metadata"`.

## Визуально / регрессии

Проверено на production preview:

- Главная и карусель «Популярные» (5 слайдов) отображаются.
- Переход в категорию / галерея с превью.
- Typecheck `@tshirt/kiosk-operator-app` и `@tshirt/point-server` — без ошибок.
- Холст 1080×1920 не менялся.
- Редактор дизайна в релизе остаётся (ленивая подгрузка); панели настройки темы — только в dev.

Намеренные визуальные отличия на Android/слабых клиентах: фон CSS, рамка без вращения, переходы без размытия, чуть легче мокапы футболок.

## Как повторить замер

```bash
# API должен слушать :4000
pnpm --filter @tshirt/kiosk-operator-app run build
pnpm --filter @tshirt/kiosk-operator-app exec vite preview --host 127.0.0.1 --port 4173

# в другом терминале:
set KIOSK_PERF_URL=http://127.0.0.1:4173/kiosk?native=1
node scripts/perf-kiosk.mjs my-label
```

Превью каталога для уже лежащих файлов:

```bash
pnpm --filter @tshirt/point-server exec tsx ../../scripts/backfill-thumbs.mjs
```
